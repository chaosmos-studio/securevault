# SecureVault Website

Marketing website for SecureVault - a privacy vault app that disguises itself as everyday applications.

## Commands

| Command           | Action                   |
| :---------------- | :----------------------- |
| `npm install`     | Install dependencies     |
| `npm run dev`     | Start dev server         |
| `npm run build`   | Build for production     |
| `npm run preview` | Preview production build |

## About

SecureVault disguises as calculator, clock, mood tracker, or notes app to hide your private photos and files.
